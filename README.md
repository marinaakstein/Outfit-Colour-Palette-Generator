Outfit Colour Palette Generator

The Project Overview:
This project is an interactive outfit colour palette generator created for my Creative Coding A2 project.

The generator creates colour palettes for fashion and styling inspiration. Users can choose from different themes including Y2K, Earthy, Bold, Grunge and Soft, or select "Surprise Me" to randomly generate a theme.

The Features:
- Five different fashion colour themes
- Interactive dropdown menu
- Generate Palette button
- Surprise Me option
- Randomly generates five different colours
- Displays colour names and hex codes
- Visual colour palette output

This project uses:

- Variables
- Lists and dictionaries
- Functions
- Random selection
- Loops
- Conditional statements
- User interaction
- Visual output using matplotlib

How to run the project:

1. Download or open `Outfit_Colour_Palette_Generator.ipynb`
2. Open the file using Google Colab
3. Select **Runtime > Run all**
4. Choose a theme from the dropdown menu
5. Click **Generate Palette**
6. A five-colour outfit palette will appear

Coding Environment:

The prototype was created using Python in Google Colab.

The project uses:

- Python
- random
- matplotlib
- ipywidgets
- IPython.display
